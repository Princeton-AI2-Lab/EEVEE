# EEVEE Project Page

This branch contains the static project page for:

**EEVEE: Towards Test-time Prompt Learning in the Real World for Self-Improving Agents**

Open `index.html` directly in a browser, or publish the repository root with GitHub Pages.

Paper: https://arxiv.org/abs/2606.11182

Assets:

- `assets/paper.pdf`: project paper.
- `assets/video.mp4`: video introduction optimized for GitHub Pages.
- `assets/logo.png`: project logo.
- `assets/figures/`: figures copied from the paper source.
- `static/css/site.css`: page styling.
